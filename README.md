# 🌿 Medicina Ancestral

Plataforma para preservar y compartir el conocimiento ancestral de plantas medicinales del pueblo Siapidara.

## 📋 Características

- ✅ Registro e inicio de sesión de usuarios
- ✅ Perfil de usuario con edición de datos
- ✅ Cambio de contraseña
- ✅ Recuperación de contraseña
- ✅ Contribuciones de saberes ancestrales
- ✅ Visualización de contribuciones en tiempo real
- ✅ Diseño responsivo

## 🛠️ Tecnologías utilizadas

- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: PHP
- **Base de datos**: MySQL (XAMPP)
- **Control de versiones**: Git & GitHub
